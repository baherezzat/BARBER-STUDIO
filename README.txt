THE GENTLEMAN — BARBER STUDIO
موقع حلاقة رجالي فاخر مع نظام حجز متكامل (صالون / زيارات منزلية / باقات عريس)
====================================================================

## التشغيل
افتح ملف index.html مباشرة في المتصفح — لا يحتاج أي خادم أو تثبيت.
يمكن رفع المجلد كاملًا على أي استضافة ثابتة (GitHub Pages, Netlify...).

## تعديل البيانات (الأهم)
كل شيء قابل للتعديل من ملف config.js فقط:
- اسم الصالون والشعار:        salonName, slogan
- رقم الهاتف ورقم واتساب:      phone, whatsapp
  (ضع رقمك الدولي بدون + في whatsapp مثل 2010xxxxxxxx)
- العنوان وساعات العمل:        address, workingHours
- الخدمات والأسعار والمدد:      services
- باقات العريس:                groomPackages
- أحدث القصات:                 haircuts
- المواعيد المتاحة:            timeSlots, workingDays
- رسوم الانتقال بالمناطق:       transportFees
- الأسئلة الشائعة:             faq
- روابط التواصل الاجتماعي:     social

## لغة الموقع
زر AR/EN أعلى الصفحة يبدّل اللغة والاتجاه (RTL/LTR) بالكامل.

## كيف يعمل الحجز
1. العميل يختار نوع الحجز (صالون / منزلي / عريس / جماعي).
2. يختار الخدمات والكميات → يُحسب السعر والمدة تلقائيًا.
3. يختار التاريخ من تقويم يمنع الأيام الماضية، والوقت من فترات العمل.
4. يدخل بياناته (حقول العنوان تظهر فقط للزيارات الخارجية).
5. يراجع الملخص الكامل (خدمات + رسوم انتقال + إجمالي).
6. زر الإرسال يفتح WhatsApp برسالة منظمة بكل التفاصيل.
   الحجز يصبح مؤكدًا فقط بعد تواصل الصالون مع العميل.

## الصور
مجلد assets/images يحتوي صور WebP مولّدة احترافية كبيانات تجريبية.
لاستبدالها بصور حقيقية: حافظ على نفس أسماء الملفات أو حدّث المسارات في config.js.
كل الصور بها fallback تلقائي في حالة الفشل في التحميل.

## بنية الملفات
index.html  — هيكل الموقع
style.css   — كل التنسيقات
script.js   — التفاعل ونظام الحجز والترجمة
config.js   — كل البيانات القابلة للتعديل
assets/     — الصور والأيقونات
